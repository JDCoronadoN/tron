## Descripción
Juego snake-like con gráficos 3D, de juego rápido y sencillo inspirado en TRON.

## Características
- Gráficos 3D estilo neón
- Jugabilidad rápida y adictiva
- Sistema de estelas lightwall
- Controles simples y responsivos

## Controles
- **W**: Acelerar
- **A/D**: Girar izquierda/derecha
- **Click Derecho**: Activar/desactivar estela
- **Tab**: Liberar/ocultar mouse

## Instalación
1. Descarga el ejecutable para tu plataforma
2. Ejecuta el juego
3. ¡Disfruta!
